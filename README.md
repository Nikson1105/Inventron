    <h2>What is CodeIgniter?</h2>

    <p>
        CodeIgniter is an application development framework — a toolkit —
        for people who build websites using PHP.
    </p>

    <p>
        Its goal is to enable you to develop projects much faster than
        you could by writing code from scratch. It provides a rich set
        of libraries for commonly needed tasks, along with a simple
        interface and logical structure for accessing those libraries.
    </p>

    <p>
        CodeIgniter allows developers to focus creatively on their
        projects by minimizing the amount of code needed for common tasks.
    </p>
